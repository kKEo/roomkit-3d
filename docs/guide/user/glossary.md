# Glossary

This page defines the words used in this guide, in the sense this guide uses them.

| Word | Meaning |
| --- | --- |
| **Block** | A special piece of panel content: `stats`, `cards`, `list`, `timeline` or `form`. |
| **Decor** | Objects listed in `scene.json` that are not points of interest, such as doors. Visitors cannot click them. |
| **Diamond** (marker) | The small floating shape above each point of interest. Clicking it takes you there. |
| **Kicker** | The small grey line above the panel title, such as "02 of 06 · west wall". |
| **Label** | The small box with a number and name that hangs above each diamond. |
| **Lead** | The first paragraph after the panel title, shown slightly larger. |
| **Markdown** | The plain-text writing format used for panels: `#` for titles, `**bold**`, `-` for lists. |
| **Object** | A thing standing in the room: a desk, frame, wardrobe, screen and so on. Chosen by its `type`. |
| **Panel** | The text box that slides in from the right (or from the bottom on phones) at each stop. |
| **Point of interest** (POI) | One stop on the walk: one or more objects, a camera position and a panel. One file each. |
| **Position** | Three numbers, `[across, up, depth]`, in metres, saying where something is in the room. |
| **Props** | The settings of an object, such as a frame's `width` or a desk's `screen`. |
| **Rain** | The falling green characters shown on screens, with the current stop's screen label in the middle. |
| **Rotation** | Three angles in degrees. The middle one turns an object to face a different wall. |
| **Scene** | One room: a folder in `public/scenes/` with its own `scene.json`, points of interest and content. |
| **Screen label** | The words in the middle of the rain screens while a visitor is at a stop. |
| **Theme** | The colours, fonts and screen effects of a scene, set in `scene.json`. |
