# Part IV: Extending

This part shows how to add new building blocks that content authors can then use from config. A prefab or block compiled into the app needs a rebuild and a redeploy; a prefab shipped inside a scene folder needs neither.

- [Adding a prefab](prefab.md): a new built-in object `type`.
- [Adding a content block](block.md): a new fenced block for panels.
- [Scene-shipped prefabs](scene-prefabs.md): an object type that lives in the scene folder and is imported at runtime.
