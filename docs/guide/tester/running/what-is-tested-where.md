# What is tested where

This page maps each area of the product to the check that covers it today and names the gap, so a reviewer knows what to look at by hand for a given change. "Explore" means the [exploratory checklist](../exploring/exploratory.md).

| Area | Code | Covered today by | Gap |
| --- | --- | --- | --- |
| Config schema and defaults | `src/config/schema.js`, `defaults.js` | `test/schema.test.js`, `test/deepMerge.test.js`: good and bad input, exact error lines | — |
| Scene building: merge, media URLs, auto-placement, errors | `src/config/buildScene.js` | `test/buildScene.test.js` (in-memory fixture: missing file, bad JSON, duplicate ids, unknown props, media resolution); `test/scenes.test.js` builds every shipped scene | — |
| Loader: scene choice, fetch, HTML fallback | `src/config/loadScene.js` | step 2 | the fetch glue itself (about 40 lines, including `loadIndex`) has no test |
| Code origins | `src/config/origins.js`, `src/lib/semver.js` | `test/origins.test.js` (page and scenes origin, the runtime list from `scenes/index.json › prefabOrigins`, `*`, merging with `VITE_PREFAB_ORIGINS`, junk entries dropped); `test/semver.test.js` (`requires` ranges); `test/buildScene.test.js` (a module written for a later SDK, a bad range, no `component`) | a real cross-origin module host and the CSP: explore |
| Auto-placement | `src/lib/autoCamera.js` | `test/autoCamera.test.js`: position, rotation, scale, default height; every prefab's hints | — |
| Prefab metadata | `src/prefabs/*.meta.js`, `registry.js`, `metaSdk.js` | `test/registry.test.js`: defaults validate, unknown keys rejected, placement finite, media keys exist, presentation fields (`title`, `blurb`, `glyph`, `requires`) kept and typed; `test/externalPrefab.test.js`: the `loft` lamp follows the contract, `META_SDK` has a version and no React | — |
| Prefab geometry | `src/prefabs/*.jsx` | the prefabs used in the example scenes, by eye | `primitive` with every shape, prop edge cases (`count: 1`, `chair: false`, a `controlDesk` with 1 or 9 screens) |
| Block and screen schemas | `src/ui/blocks/schema.js`, `src/prefabs/screenSchema.js` | `test/blocks.test.js` | fenced blocks inside Markdown are validated only when rendered (step 3) |
| Screens | `src/prefabs/media.jsx`, `src/scene/screens.js` | images in `gallery`; every other source (`text`, all three `graph` styles, `stats`, own rain with colour, image, `terminal`, `dashboard`, `form`) on the `neo-room` control desk; pure drawing helpers (`keepTyped`, `valueRange`, `scaleSeries`, `graphReadout`, `statsGrid`, `isHls`) in `test/liveScreens.test.js` | video plays on the `cinema` big screen (`media/intro.mp4`), checked by hand only; HLS is checked by hand only (explore). Canvas drawing itself has no unit test. Unknown `source` fallback is untested |
| Live data: feeds, transforms, hub | `src/data/` (`feedSchema.js`, `hub.js`, `feeds.js`, `useFeed.js`, `live.js`), `src/config/origins.js` | `test/feedSchema.test.js` (schemas, block and screen feed rules); `test/feeds.test.js` (sharing, polling, abort, backoff, hidden tab, SSE, guard, `fetchJson`, `guardData`); `test/liveScreens.test.js` (`mergeLive`); `test/buildScene.test.js` (transform loading, unknown transform paths); `test/scenes.test.js` runs every shipped transform on its local data | the React hooks (`useFeed`, `useLiveScreen`) and `FeedBlock` are checked by hand (explore); a real cross-origin host and CORS failures only by hand |
| Screen zoom and overlays | `src/ui/ScreenOverlay.jsx`, `src/ui/screens/`, `src/scene/screenState.js` | explore ([Zoomed-in screens](../exploring/exploratory.md#zoomed-in-screens)); dashboard filtering in `test/dashboard.test.js` | overlay alignment under 760 px and on touch devices has not been checked; terminal command parsing has no unit test |
| Camera and transitions | `src/scene/CameraRig.jsx` | explore | everything; motion is checked only by eye |
| Input | `src/ui/useInput.js` | explore | everything |
| Editor: templates, zip, import, export | `src/editor/bundle.js`, `zip.js`, `unzip.js`, `export.js` | `test/editor.test.js` (CRC-32, zip layout, every prefab's template as scenery and as a stop, scene registry); `test/unzip.test.js` (stored and deflated entries, UTF-8 names, damaged input); `test/export.test.js` (options in `scene.json`, referenced files of the shipped `cinema` and `neo-room`, fenced feeds, modules from the web left out and listed by `hostedModules`, folder and site layout, `importZip` on site, folder and bare zips) | `fetchBundle`, `fetchBytes`, object URLs and `EditorApp` itself: explore ([Editor: export a site](../exploring/exploratory.md#editor-export-a-site)) |
| Editor: object types from the web | `src/editor/catalog.js`, `AddTypeDialog.jsx`, the `prefabs` helpers in `tree.js` | `test/catalog.test.js` (format version, relative URLs resolved against the catalog, every rejected shape, the shipped sample catalog); `test/tree.test.js` (declaring and removing types in `scene.json` keeping its layout, refusals, type names suggested from URLs); `test/buildScene.test.js` (`loadPrefab`, the check the dialog runs) | the dialog itself, the Room's type list and a blocked origin: explore ([Editor: object types from the web](../exploring/exploratory.md#editor-object-types-from-the-web)) |
| Editor: scene tree, inspector, JSON edits | `src/editor/tree.js`, `jsonEdit.js`, `form.js`, `Tree.jsx`, `Inspector.jsx`, `AddMenu.jsx`, `Menus.jsx`, `src/scene/EditMarks.jsx`, `Gizmo.jsx` | `test/tree.test.js` (layout-keeping edits; the tree of the shipped `cinema`; error lines to nodes; add, make a stop and back with each step built; naming a new stop; moves keeping an object's text; dissolve, delete, duplicate, reorder; references to a stop; where new objects land); `test/form.test.js` (fields from every built-in schema); `test/math.test.js` (`configRotation`: plain yaws past 90°, same orientation) | the React components, drag and drop, keyboard, picking in the room, the selection box and the move / rotate handles: explore ([Editor: scene tree](../exploring/exploratory.md#editor-scene-tree)) |
| Editor: screens and clicks | `src/editor/screenForm.js`, `ScreenEditor.jsx`, `fields.jsx` | `test/screenForm.test.js` (sources and their keys, screen props found by schema, hotspots of the control desk, desk and cinema screen, problems per key, writing out default lists, source changes dropping keys, zoom / nothing / action, renaming moves the action, actions following added, moved and removed screens, a moved screen keeping its text, a cinema screen's `source` / `src` into a config) | the components, picking a screen in the room, the outline: explore ([Editor: screens](../exploring/exploratory.md#editor-screens)) |
| Viewer file list | `tools/viewer-bundle.js` | `test/viewerBundle.test.js` (`viewerFiles` filter, `writeManifest`) | the `/__viewer` dev middleware and the on-demand build: explore |
| Panel and blocks | `src/ui/Panel.jsx`, `Markdown.jsx`, `blocks/` | step 3 | form `action` POST path |
| Labels, minimap, progress | `src/ui/Labels.jsx`, `Minimap.jsx`, `Overlays.jsx` | explore | alignment of labels with diamonds |

| Responsive and reduced motion | CSS media queries, `src/lib/env.js` | explore | everything |
